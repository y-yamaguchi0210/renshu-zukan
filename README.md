# 低学年バレー練習図鑑（ウェブアプリ）

スポ少バレー1・2年生向けの練習99種目を、スマホで探してメニューを組み、タイマーで進めるアプリです。

## できること
- 名前や道具で検索、テーマ・ボール・人数・道具なしで絞り込み
- お気に入り登録
- 今日のメニュー作り（おまかせ作成、時間の変更、並べかえ、水分補給、保存、文章でコピー）
- タイマーで進める実施画面（時間切れで音と振動。対応端末では画面が消えにくくなります）
- 一度開けば、電波がなくても使えます

## 公開のしかた
1. https://app.netlify.com/drop を開く
2. このフォルダごとドラッグ＆ドロップする
3. 発行されたURLをスマホで開き、ブラウザのメニューから「ホーム画面に追加」を選ぶ

`index.html` をダブルクリックしても動きますが、電波なしの機能とホーム画面への登録は、公開したURLからでないと使えません。

## データの保存先
お気に入りとメニューは、使っている端末のブラウザの中だけに保存されます。ほかの人や別の端末とは共有されません。ブラウザのデータを消すと消えます。
